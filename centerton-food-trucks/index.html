How updates work

Every menu on this page lives in one simple list. When a truck changes a price or a new truck rolls in, the truck can text or email a menu photo to Jackson (or the park forwards it), and it is on the site the same day. There is no software for you or the trucks to learn. If you would rather edit it yourselves, it can run from a free Google Sheet you control.

Each menu shows where it came from and when it was posted or checked.

Truck owners: send the park your menu to get it on this page.
